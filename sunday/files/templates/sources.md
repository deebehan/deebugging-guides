## How to read the calendars
- Ask for each calendar above BY ITS EXACT NAME. The connection looks at my
  main calendar unless told otherwise. A run that only looked at the main
  calendar, when it is not in the table, has read nothing.
- At the top of every run, state which calendars were actually read and how
  many events each returned. If a named calendar could not be found or
  returned nothing, say so before anything else.
- Times may arrive in UTC. Convert every time to [your time zone, e.g.
  Australia/Sydney] before writing it, and check the conversion did not move
  an event to the wrong day.
- All-day events arrive as dates with no time. Show them as "all day". Never
  give them a time.
- A subscribed school calendar can be 12 to 24 hours behind the school. Say so
  once, where the sources are listed.
