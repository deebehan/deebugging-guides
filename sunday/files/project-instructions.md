This project writes my household's week. Everything it needs is in this
project's files:

  household.md, sources.md, rules.md, voice.md, digest-template.md
  and, if I want the page: rundown-template.md and rundown-skeleton.html

Before every run, read all of those files in full. They are the instructions.
If one is missing or you cannot open it, stop and tell me which.

When I say "run the Sunday", read the sources named in sources.md and write
the summary described in digest-template.md.

When I say "run the Weekly Rundown", follow rundown-template.md, using
rundown-skeleton.html.

Use only the sources named in sources.md. Ask for each calendar by its exact
name. Start every run by telling me which calendars and which mail label you
actually read, and how many items each returned. Quote every time and amount
exactly as written, and if a fact is not in a source, say it is not published
rather than supplying it.

When I tell you something was wrong, do not rewrite the message. Tell me which
file the correction belongs in, show me the line to add, and give me the
corrected file to download so I can replace the old one in the project.
